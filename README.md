# Сити-Центр · Расширение 2027

Рабочий сайт по [Google Таблице](https://docs.google.com/spreadsheets/d/17VLUhYE2MeV78FpBGQdUhig3JvAh2j_HaQ3GlzqCpIE/edit). Обзор проекта, 49 городов с поиском и фильтрами, три финансовых сценария, 38 месяцев денежного потока, команда и найм, план пилота и контрольные условия.

**Статус:** модель от 07.10.2026, снимок прочитан 29.10.2026. Пять офисов не рекомендованы к финансовому утверждению; смета неполная. Уфа — предложенный, не утверждённый город пилота.

## Локальный запуск

Нужен Python 3; установка пакетов и сборка не требуются.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000`. Двойной щелчок по `index.html` не подходит: браузер блокирует чтение JSON через `file://`.

Для проверок нужен Node.js 22+: `npm run check`. На сайте работают поиск, округ и наличие цен, сортировка, карточки кандидатов, сценарии, фильтр денежного потока по годам, текстовый отчёт, CSV и печать. Состояния навигации поддерживают прямые ссылки, например `/#finance`.

Автономную копию, которую можно открыть двойным щелчком без сервера, создаёт `node scripts/make-offline.mjs`. Она содержит данные внутри HTML и не обновляется автоматически. Файл содержит финансовую информацию так же, как основной сайт.

## Данные и ограничения

- `data/snapshot.json` — сохранённые значения семи основных листов. Google Таблица не изменялась.
- Сравнение трёх сценариев взято из снимка «Паспорта решения» на 07.10.2026. Переключатель меняет представление сохранённых результатов; это не новый расчёт формул.
- Помесячные ряды относятся к **базовому** сценарию. При выборе другого сценария обзор показывает сравнение финансирования вместо вымышленного помесячного графика.
- Входы, доходность и CAC остаются гипотезами там, где так указано в источнике. Отсутствующие цены не заменяются нулями.
- Все ссылки на исходные листы ведут к исходной таблице и требуют прав Google.
- Никакие учётные данные Google в клиентский код не передаются. Внешний ресурс оформления — Google Fonts; при недоступности используется системный шрифт.

## Публикация на GitHub Pages

[Репозиторий проекта](https://github.com/hoglax/fivenewcities) открыт. Сайт и JSON-снимок содержат данные финансовой модели и доступны публично. `noindex` — просьба не индексировать сайт, а не ограничение доступа.

Публикация:

1. В **Settings → Pages → Build and deployment** должен быть выбран **GitHub Actions**.
2. Изменения в `main` автоматически запускают **Publish website to GitHub Pages**. Также доступен ручной запуск во вкладке **Actions → Run workflow**.
3. Готовая ссылка появится в успешном deployment. Ожидаемый адрес проекта: `https://hoglax.github.io/fivenewcities/`.
4. Коммиты ежедневной синхронизации создаются с `GITHUB_TOKEN`: GitHub не запускает от них другой workflow автоматически. После синхронизации опубликуйте обновлённый снимок ручным запуском Pages.

GitHub Pages не предоставляет обычную парольную защиту. Для закрытого сайта следует выбрать хостинг с проверкой доступа.

## Автоматическое чтение закрытой таблицы

Без авторизации Google возвращает HTTP 401. Поэтому сайт сейчас работает со снимком. В репозитории подготовлена ежедневная синхронизация через Google Sheets API; **она пока не настроена**.

1. В своём Google Cloud проекте включите Google Sheets API и создайте отдельный service account.
2. Предоставьте его адресу только **Viewer / Читатель** к исходной таблице. Не делайте таблицу публичной.
3. Сохраните JSON-ключ в **Settings → Secrets and variables → Actions → New repository secret**, имя `GOOGLE_SERVICE_ACCOUNT_JSON`. Не коммитьте ключ и не отправляйте его в переписку.
4. В таблице оставьте активным **Базовый** сценарий. Скрипт не изменяет переключатель: чтение строго read-only.
5. Запустите workflow **Update Google Sheets snapshot**. Далее он запускается ежедневно в 05:17 UTC; без секрета корректно пропускает чтение и сохраняет существующий снимок.

При изменении структуры таблицы проверьте отображение и диапазоны в `scripts/sync-sheet.mjs`. Скрипт проверяет число городов и активный сценарий, а workflow — денежные сверки перед коммитом. Дата снимка меняется при чтении; дата сценарного сравнения остаётся датой исходного сохранённого сравнения.

## Структура

```text
index.html, styles.css, app.js     Сайт без сборки и фреймворков
data/snapshot.json                Снимок семи основных листов
scripts/check-data.mjs            Сверки модели и полноты данных
scripts/sync-sheet.mjs            Чтение Google Sheets API
.github/workflows/pages.yml       Публикация Pages при push в main и вручную
.github/workflows/sync-sheet.yml  Ежедневное обновление снимка
```
